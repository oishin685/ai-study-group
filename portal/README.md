# AI部 学びのポータル

AI部の無料・初歩的な教材をまとめる、1ページのポータルです。カードとカテゴリは `data/contents.json` で管理します。

## 新しい教材を追加する手順

1. 教材ページまたは外部URLを用意する
2. `data/contents.json` の `contents` にカード情報を1件追加する
3. ローカルサーバーで表示とリンクを確認する
4. GitHub Pagesへ反映する

ローカル確認はリポジトリのルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/portal/` を開きます。ファイルを直接開くと、ブラウザの制限でJSONを読み込めない場合があります。

## カードの編集

- 表示順：同じカテゴリ内の `order` を変更します。
- 準備中：`status` を `coming-soon`、`url` を空文字にします。
- リンク設定待ち：`status` を `link-pending`、`url` を空文字にします。
- 外部リンク：`url` に `https://` から始まる正式URLを入れ、`external` を `true` にします。リンクは同じタブで開きます。
- 説明文：`description` を変更します。
- ラベル：`badge` を変更します。空文字なら表示されません。

`status` が `active` でも `url` が空の場合は、誤移動を防ぐためリンクになりません。

## カテゴリの追加と並べ替え

`categories` に `id`、`title`、`order` を追加します。カード側の `section` に同じ `id` を設定してください。カテゴリの順番は `order` で変更できます。

新しいカテゴリには、`styles.css` に `.section-カテゴリID` の背景色を追加できます。色だけに意味を持たせず、見出しでもカテゴリを示してください。

## アイコンの追加

`app.js` の `iconPaths` に、24×24のSVG用パスを追加します。キー名をカードの `icon` に設定してください。アイコンは装飾扱いで、読み上げから除外されます。

## 公開前の確認

- 320px、375px、390px、430px、768px、1280pxで横スクロールや重なりがない
- キーボード操作でリンクへ移動でき、フォーカスが見える
- 有効な全リンクが開く
- 準備中・リンク設定待ちのカードにリンクがない
- コンソールエラーがない
- 既存教材のファイルに意図しない変更がない
